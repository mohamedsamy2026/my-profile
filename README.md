# Mohamed Samy — Portfolio (Vite + React + Tailwind, JavaScript only)

`npm install` then `npm run dev`.

- **Personal photo:** replace `public/assets/mohamed-samy-hero.png`
- **Project images:** add `public/assets/project-1.png` … `project-5.png` (a placeholder shows until they exist)
- **Projects:** `src/data/projects.js` (titles, tags, Live Demo / GitHub links)
- **Testimonials:** `src/data/testimonials.js`
- **English / Arabic text:** `src/data/translations.js` (services in `services.js`, projects in `projects.js`)
- **Contact info & social links:** `src/data/social.js`
- **Themes:** toggle in navbar/footer; colors are CSS variables in `src/index.css` (`:root` = light, `.dark` = dark)
- **Contact form:** frontend-only; connect a backend in `src/components/Contact.jsx` (`submit`)
